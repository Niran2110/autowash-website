# AutoWash - Car Washing & Detailing Website

A responsive car washing and detailing website developed using HTML5 and CSS3.

## 📌 Project Overview

AutoWash is a responsive car washing and detailing website that provides
information about washing services, pricing plans, service locations,
engineers and workers, customer testimonials and contact options.

## ✨ Features

- Responsive navigation bar
- Hero section
- Car washing and detailing introduction
- Premium washing services
- Service statistics
- Washing plans and pricing
- Car washing and care points
- Car wash request form
- Engineers and workers section
- Customer testimonials
- Newsletter section
- Responsive footer
- Mobile, tablet and desktop layouts

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Responsive Web Design
- CSS Media Queries

## 📱 Responsive Design

The website is designed for:

- Mobile devices
- Tablets
- Laptops
- Desktop screens
